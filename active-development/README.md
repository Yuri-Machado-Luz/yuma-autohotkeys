# Active Development

Playground com scripts em desenvolvimento e experimentação.

## ⚠️ ATENÇÃO

**Não use esses scripts em produção.** Arquivos neste diretório:

- Podem estar incompletos ou com bugs
- Servem para prototipagem e ideias
- São versões que precedem implementações estáveis em `plug-n-play/`

## Arquivos

### playground.ahk

Compilado de snippets variados para testes e experimentação. Contém:

- Tentativas de diferentes padrões e soluções
- Código que serão modificados
- Prototipagem de novas funcionalidades
## Como usar

Se quer testar uma ideia:

1. Copie um snippet de `playground.ahk` ou crie um novo arquivo
2. Teste localmente no seu `active-development/`
3. Quando estável e testado, procure um arquivo similar em `../plug-n-play/` para migrar
4. Se for uma feature nova, considere abrir uma PR depois

## Boas práticas

- Use comentários liberalmente
- Documente seu pensamento experimental
- Link para issues ou PRs relacionadas quando possível
